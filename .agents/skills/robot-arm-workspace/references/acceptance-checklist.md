# Workspace acceptance checklist

- Repository and workspace roots are identified.
- ROS distro and overlay sourcing are known.
- Every affected package and dependency is identified.
- Description, controller, MoveIt and task configs use consistent joint names.
- A reproducible launch sequence is documented.
- Package-specific build and test commands pass.
- Simulation and physical-hardware results are clearly distinguished.
- No destructive or hardware-moving command was run without approval.
